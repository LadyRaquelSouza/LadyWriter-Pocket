# Build experimental da marca LadyWriter Pocket · 24/11/2026

Este arquivo registra a tentativa de compilar no GitHub Actions o primeiro APK
com identificador fixo, assinatura persistente e ícone próprio de ponta de caneta.

**Arte de origem:** [SVG](ladywriter-pocket-icon.svg) ·
[VectorDrawable](ladywriter-mark.xml) ·
[ícone temático](ladywriter-mark-monochrome.xml).

O workflow só prossegue para download/compilação do motor se os dois Secrets
de assinatura estiverem presentes. O código do app continua experimental.
